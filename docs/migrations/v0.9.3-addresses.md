This migration has not established a redirect/alias for either old public address: plan to replace saved entry links and QR codes. Same-origin Pages path changes leave browser storage under the same origin, but path construction and recovery must still be tested. A Netlify hostname change crosses origins: existing browser credentials will not automatically appear at the new hostname. Do not copy credentials into public documentation or broad redirects.

If verification fails, use the captured frontend/Worker/proxy configuration and documented account rollback options. A retired hostname may not be reclaimable; do not rely on reverse-renaming as the only rollback. Pause cutover if account state prevents an independently verified recovery route.
